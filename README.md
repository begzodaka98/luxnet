# ИНСТРУКЦИЯ ПО АДМИНИСТРИРОВАНИЮ МАГАЗИНА NETCOM

Обычные покупатели видят только чистый интернет-магазин (каталог, цены, корзину, оформление в Telegram) и **не имеют доступа к настройкам таблицы**.

Все технические настройки скрыты под паролем.

---

## 🔐 1. Как войти в закрытую Админ-панель?

Вы можете войти любым из 3 удобных способов:

1. **Через адрес сайта:** просто добавьте `?admin` в конец ссылки:
   👉 `https://ваш-сайт.uz/?admin`  
   *(или при локальном запуске: `index.html?admin`)*
2. **Горячими клавишами:** нажмите на клавиатуре:
   👉 **`Ctrl + Shift + A`** *(или `Cmd + Shift + A` на Mac)*
3. **Секретным кликом:** быстро нажмите **3 раза подряд** на текст копирайта в самом низу сайта (*«© 2026 NETCOM. Все права защищены»*).

---

## 🔑 2. Пароль администратора

- Стандартный пароль: **`admin`**
- Чтобы изменить пароль на свой собственный, откройте файл **`config.js`** в любом текстовом редакторе и измените значение:
  ```javascript
  adminPassword: "ваш_надежный_пароль",
  ```

После успешного ввода пароля в шапке сайта появится кнопка **«Админ-панель»**, через которую вы сможете в любой момент:
- Менять ID Google Таблицы
- Принудительно обновлять каталог одной кнопкой
- Изменять курс доллара
- Быстро переходить к редактированию самой Google Таблицы в новой вкладке

---

## 📊 3. Подключение вашей Google Таблицы

1. Откройте Google Таблицу со списком товаров (или импортируйте шаблон `template_google_sheet.csv`).
2. Колонки таблицы должны быть:
   `id | brand | category | title | price | oldPrice | badge | image | inStock | specs | description`
3. Нажмите в таблице **«Поделиться»** -> выберите **«Все, у кого есть ссылка» (Читатель)**.
4. Скопируйте ID таблицы из ссылки (символы между `/d/` и `/edit`).
5. Войдите в админ-панель на сайте, вставьте ID и нажмите **«Сохранить настройки»**.
6. При добавлении или изменении цен в Google Таблице просто нажмите кнопку **«Обновить»** в админ-панели.
